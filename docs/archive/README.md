# Archived documentation

Materials kept for historical context but not part of the polished
submission surface. Each file falls into one of three buckets:

- **Pre-SRL trial-run results** — single-host Rocba results from
  the first iterations of process_analyst, network_analyst, and the
  orchestrator. Superseded by the SRL-2015 numbers in
  `../accuracy-report.md`.

- **Design-phase notes** — agent-harness selection rationale, loop
  design, validator design, dispatch plan for Rocba, synthetic-demo
  image generation, volatility smoke-test transcript. These
  predate the working code; the code now embodies the decisions.

- **Protocol SIFT reference** — `protocol-sift/` is a snapshot of
  Protocol SIFT's relevant files plus a short comparison
  (`protocol-sift-assessment.md`) we made while choosing our
  baseline. Kept for the curious; not part of the submission.

The polished, user-facing docs (the eight Devpost deliverables) live
one level up under `../`.
